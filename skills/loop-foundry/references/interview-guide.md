# 인터뷰 가이드

한 번에 한 질문만 한다. 이미 답한 내용을 다시 묻지 않는다.

## 1단계: 업무 후보

첫 질문:

> 최근 한두 달 동안 두 번 이상 반복한 일 가운데, 다음에도 다시 할 가능성이 높은 일은 무엇인가요?

사용자가 여러 개를 말하면 반복 빈도, 입력의 유사성, 결과물의 중요도로 하나를 고르게 돕는다.

## 2단계: 업무 경계

다음 순서로 확인한다.

1. 이 일은 무엇이 생기면 시작되는가?
2. 시작할 때 받는 입력은 무엇인가?
3. 끝났다고 판단할 수 있는 산출물은 무엇인가?
4. 반드시 사람이 결정해야 하는 지점은 무엇인가?
5. 자동으로 하면 위험하거나 원하지 않는 행동은 무엇인가?

## 3단계: 실제 사례

최근 사례를 요청한다.

> 실제 입력과 당시 만든 결과물을 한 쌍 보여주세요. 민감한 정보는 지우거나 익명화해도 됩니다.

각 사례에서 다음만 추출한다.

- 입력 유형
- 반복되는 작업 단계
- 반드시 남아야 하는 결과 요소
- 실패 또는 재작업의 원인
- 사용자가 최종 확인한 판단

## 4단계: 사례 분할

가능하면 3개 이상을 받는다.

- train: 1~2개
- heldout: 최소 1개

사례가 2개뿐이면 train 1 / heldout 1로 시작한다. 사례가 1개뿐이면 인터뷰로 초안을 만들되 게이트 미검증 상태임을 명시한다.

## 질문을 멈춰야 할 때

다음이 모두 명확하면 인터뷰를 끝낸다.

- 시작 신호
- 입력
- 산출물
- 성공과 실패의 차이
- 승인 경계
- train과 heldout 구분
