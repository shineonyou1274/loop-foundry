Claude Code

Claude Code에 두 명령을 순서대로 실행해 달라고 요청합니다.

다음 Claude Code 명령을 순서대로 실행해서 Loop Foundry를 설치해줘.

/plugin marketplace add shineonyou1274/loop-foundry
/plugin install loop-foundry@loop-foundry

설치 후 새 세션에서 loop-foundry 스킬을 사용할 수 있다고 알려줘.
